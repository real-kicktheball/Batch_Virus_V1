⚽ KickTheBall Virus (v1.0)
⚠️ 경고: 본 프로그램은 교육 및 시뮬레이션용 가상 바이러스입니다. > 이 프로그램은 실제 시스템을 파괴하지 않지만, 시스템 재시작 및 프로세스 종료와 같은 동작을 포함하고 있습니다. 실행 시 주의가 필요합니다.

📝 개요
KickTheBall Virus는 Windows 환경에서 작동하는 배치 파일 기반의 바이러스 시뮬레이터입니다. 감염된 척하는 연출과 함께 특정 퀴즈를 풀어야 시스템이 정상화되는 일종의 '미니 게임' 요소를 담고 있습니다.

✨ 주요 기능 및 동작
시스템 종료 예약: 실행 시 300초(5분) 후 자동 종료 타이머가 작동합니다.

자동 실행 등록: %APPDATA%의 시작프로그램 폴더에 자신을 복사하여 재부팅 시에도 실행되도록 설정합니다.

UI 차단: explorer.exe를 강제 종료하여 작업 표시줄과 바탕화면 아이콘을 숨깁니다.

복구 퀴즈: KickTheBall의 생일(6자리)을 맞춰야만 시스템이 복구됩니다.

사운드 효과: PowerShell을 이용한 비프음 출력을 통해 긴장감을 조성합니다.

🚀 실행 방법
저장소를 클론하거나 KickTheBall.bat 파일을 다운로드합니다.

파일을 실행합니다.

화면에 나타나는 안내에 따라 6자리 비밀번호를 입력합니다.

🔓 복구 방법 (Hint)
만약 비밀번호를 잊어버렸다면 아래 내용을 확인하세요.

수동 복구:

Ctrl + Shift + Esc를 눌러 작업 관리자 실행

파일 -> 새 작업 실행 -> explorer.exe 입력

Win + R -> shutdown /a 입력하여 종료 예약 취소
